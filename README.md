# soma-net-examples

This is a repository of examples for the [soma-net](https://github.com/akshaaydev/soma-net.git) repopsitory.

To try out the examples, clone this repository alongside [soma-net](https://github.com/akshaaydev/soma-net.git) and follow the instructions for each example.

Examples:

- [XOR Gate](xor/main.cpp): Approximation of the boolean XOR gate
- [Implicit Neural Representation](inr/main.cpp): Recreation of an image
- [MNIST digit classification](mnist/main.cpp) : Recognize handwritten digits
